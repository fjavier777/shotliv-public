# Shotliv Privacy Policy

**Effective date:** November 22, 2026

## 1. Overview

Shotliv is a Chrome extension that lets users enhance images directly in their browser.

This policy explains what information Shotliv handles, how it is used, and whether it is collected, stored, or shared.

## 2. Information Handled

When a user selects an image, Shotliv handles:

- The image file selected by the user.
- The selected file's name, which is used to name the exported image.

Supported image formats are JPEG, PNG, and WebP.

This information is processed locally in the user's browser to display the image, apply brightness, contrast, and saturation adjustments, compare the original and enhanced versions, and export the result.

## 3. Collection, Transmission, and Sharing

Shotliv does not collect or transmit selected image files, image contents, or filenames to the developer or to Shotliv servers.

Shotliv does not share this information with third parties. It does not use analytics, advertising trackers, tracking cookies, external image-processing services, or cloud storage.

## 4. Local Processing and Storage

Image processing takes place locally in the browser using built-in browser technologies.

Selected image data is held in browser memory during the active editing session. Shotliv does not save selected images or adjustment settings to persistent storage.

When a user exports an image, Chrome handles the download according to the user's browser settings. The developer does not receive a copy of the exported image.

## 5. Permissions and User Actions

Shotliv does not request broad or optional browser permissions.

Users choose the files they want to edit through the browser's file selection interface. The extension only processes a file after the user selects it.

## 6. Purpose and Limited Use

Information handled by Shotliv is used only to provide its single purpose: local image enhancement and export.

Shotliv does not sell user data or use it for advertising, profiling, or purposes unrelated to the extension's functionality.

Shotliv's handling of user data is limited to the practices described in this policy and is intended to comply with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## 7. Third-Party Services

Shotliv does not integrate with external services that receive or process user-selected images.

Chrome provides the browser environment, file selection interface, and download functionality. The use of Chrome is subject to Google's own privacy terms.

## 8. Changes to This Policy

This policy will be updated if Shotliv's functionality or data practices change. Material changes will be reflected in the published policy.

## 9. Contact

A dedicated privacy contact address will be published in this section before Shotliv is publicly released.

Until then, this policy should be treated as a pre-release document.
